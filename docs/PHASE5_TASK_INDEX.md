## Maintenance Rules

1. 新 TASK 使用 `Next Task Number`。
2. 创建后立即将 Next Task Number +1。
3. 同一问题的后续调整不创建新 TASK。
4. 一个独立问题只有在确认后才占用编号。
5. Active TASK 原则上一次只有一个。
6. P0 可暂停当前 TASK 并抢占 Active。
7. TASK 进入 DONE 后记录真实完成日期。
8. Task Index 只记录索引，不复制整份 TASK 实施细节。
