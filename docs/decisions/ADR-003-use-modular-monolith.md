# 当前采用模块化单体后端

状态：Proposed  
日期：2026-07-23  
决策人：项目负责人

## 1. 背景

该决策用于约束 Information Platform 当前阶段的架构实现。

## 2. 决策

当前使用一个 Spring Boot 模块化单体应用，通过 package 和领域边界划分模块。

## 3. 决策理由

当前优先目标是以最低复杂度跑通采集、接入、归档和查询闭环。

## 4. 正面影响

- 降低开发与部署复杂度。
- 方便 Codex 在一个仓库中理解完整上下文。

## 5. 负面影响和代价

- 后续规模扩大后可能需要重新评估。

## 6. 重新评估条件

当数据规模、团队规模或独立扩容需求明显增加时重新评估。
