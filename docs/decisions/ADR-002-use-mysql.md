# ADR-002：使用 MySQL 作为当前主数据库

状态：Accepted  
日期：2026-07-23  
决策人：项目负责人

## 背景

系统需要事务、关系查询、任务状态、用户关系、推荐记录和统计，同时需要保留原始 JSON。

## 决策

使用 MySQL 8 作为主数据库，原始业务对象存 JSON 字段。当前不引入 MongoDB。

## 备选方案

- MongoDB：文档灵活，但增加第二套数据库，关系业务收益有限。
- PostgreSQL：JSONB 和 pgvector 强，但当前开发者更熟悉 MySQL。

## 重新评估条件

大规模网页快照、PDF/OCR 文档或 JSON 查询成为主要负载时重新评估；大文件优先考虑 MinIO。
