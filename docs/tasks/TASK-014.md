## 7. 业务与技术规则

- page 从 1 开始。
- size 最大 100。
- 排序字段只用后端白名单。
- 修改筛选后 page 重置为 1。
- 修改 size 后 page 重置为 1。
- URL 是列表状态的可恢复事实来源。
- 空结果不是错误。
- 不发送空字符串参数。
- 后端是参数合法性的最终裁决者。
