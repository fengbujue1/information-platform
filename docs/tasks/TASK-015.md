## 9. 实施前计划

- 详情字段严格使用 Job Query API V1 和后端 `JobDetailResponse`，不新增前端猜测字段。
- 页面拆分为详情 View、详情展示组件、详情请求组合逻辑和路由安全工具。
- `from` 只接受 `/jobs` 或 `/jobs?...`，非法值回退 `/jobs`。
- JD 使用文本插值和 `white-space: pre-wrap`，不使用 `v-html`。
- 覆盖成功、nullable、404、网络重试、非法 ID、外部链接、请求取消和迟到响应。
- 历史快照只增加最小占位入口，不调用快照 API。
